เปิด Terminal ไปที่โฟลเดอร์ที่อยากเก็บงาน แล้วพิมพ์
```bash
git clone https://github.com/yossaponc15/gdd-class2-python.git
cd gdd-class2-python
```

### 🔄 ทุกสัปดาห์: รับบทเรียนใหม่

```bash
git pull
```

## ✍️ กฎสำคัญ: ทำงานในโฟลเดอร์ `my_work/` เท่านั้น!

**ห้ามแก้ไฟล์ในโฟลเดอร์วันที่โดยตรง** ไม่งั้นครั้งหน้า `git pull` จะ error

ทุกสัปดาห์ให้ **คัดลอกโฟลเดอร์ของสัปดาห์นั้นไปไว้ใน `my_work/`** แล้วทำงานในนั้น

```text
gdd-class2-python/
├── 2026-10-10/          ← ของครู (ห้ามแก้ ❌)
├── 2026-10-17/          ← ของครู (ห้ามแก้ ❌)
└── my_work/             ← ของฉัน (แก้ได้ตามใจ ✅)
    ├── 2026-10-10/
    └── 2026-10-17/
```

**วิธีคัดลอก** (เลือกแบบไหนก็ได้)
- **ใน VS Code:** คลิกขวาที่โฟลเดอร์วันที่ → Copy → คลิกขวาที่ `my_work` → Paste
- **ใน Terminal:**
  ```bash
  mkdir -p my_work
  cp -R 2026-10-10 my_work/
  ```

> 💡 `my_work/` ถูกตั้งค่าไว้ให้ git ไม่สนใจ งานของเราจะไม่หาย และ `git pull` จะไม่มีปัญหา

## 🆘 แก้ปัญหา

| อาการ | ทางแก้ |
|---|---|
| `git: command not found` | ยังไม่ได้ติดตั้ง Git → ดาวน์โหลดที่ https://git-scm.com |
| `Your local changes ... would be overwritten by merge` | เผลอแก้ไฟล์ของครู → คัดลอกงานไปไว้ใน `my_work/` ก่อน แล้วพิมพ์ `git restore .` จากนั้น `git pull` ใหม่ |
| ไม่เห็นโฟลเดอร์สัปดาห์ใหม่ | ลืม `git pull` หรือ Terminal ไม่ได้อยู่ในโฟลเดอร์ `gdd-class2-python` |
